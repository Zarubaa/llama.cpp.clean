# 0806 Full DRAM Cache Rerun

This directory is a fresh rerun of the 0730 three-mode comparison. It uses
the same model, realistic Chinese-English prompt, pp/tg, GPU/NUMA binding,
VRAM cache sizes, ubatches, and three-process-per-cell design as the original
0730 experiment. Results are generated by `scripts/run-experiments.sh`.
