# Synthetic SERE fixture

This directory is the stable parent for generated mechanism-only inputs:

- `similarity.npz` is the deterministic uniform matrix generated by
  `../generate-synthetic-matrix.py`.
- `similarity.sere` is the model-bound V2 sidecar generated from that NPZ by
  `scripts/export-sere-similarity.py`.

Both files are generated artifacts. They verify parsing, routing, profiling and
transfer accounting only; they are not calibrated expert-similarity data and
must not be used for quality or formal performance claims.
